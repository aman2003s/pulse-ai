# Pulse

**Control your computer through natural conversation.**

Pulse is a local, voice-first AI computer companion that helps people accomplish computer tasks naturally. Simply say "Pulse", describe what you want to do, and Pulse understands your intent, performs the task, and keeps you informed throughout the entire process.

Designed with accessibility at its core. Built for everyone.

Technology should adapt to people—not the other way around.
Modern computers expect users to learn shortcuts, menus, commands, and complex interfaces before getting real work done.

For many users—especially people with visual impairments or limited mobility—those barriers can make everyday tasks frustrating.

Pulse changes that.

Instead of learning how to use software, users simply describe what they want to accomplish.

## How it Works

1. **Wake**
   Simply say:
   "Pulse."
   Pulse wakes up and responds naturally.
   "I'm listening."

2. **Understand**
   Pulse understands your intent rather than requiring exact commands.
   "Open my electricity bill."
   "Launch Chrome."
   "Find my resume."

3. **Plan**
   Pulse breaks your request into manageable actions and decides the safest path to complete the task.

4. **Execute**
   Pulse performs each step while continuously informing you about its progress.

5. **Confirm**
   Every sensitive action requires your approval before execution.

## Features

### Core Principles
- **Accessibility First**: Every interaction is designed to reduce uncertainty by keeping users informed about what Pulse is doing.
- **Voice First**: Voice is the primary interface. No complicated keyboard shortcuts are required.
- **Local & Private**: Pulse is designed to run locally using open AI models whenever possible. Your personal information stays on your computer.
- **Human Control**: Pulse never silently performs important actions. You always remain in control.

### What Pulse Can Do
- Open applications
- Open files and folders
- Understand natural language requests
- Search for documents
- Execute multi-step computer tasks
- Speak progress naturally
- Continue conversations without repeating the wake word
- Confirm important actions before execution

## 🦸 Superhero Mode

Designed for users who want continuous guidance.

Most software becomes silent once an action starts.
Pulse doesn't.

Superhero Mode provides continuous spoken feedback so users always understand what is happening.
It can also announce typing, navigation, loading states and important system events, giving users continuous awareness of their computer instead of moments of silence.

**Example Interaction**
- **User:** Pulse, enable Superhero Mode.
- **Pulse:** Superhero Mode activated. I'll guide you through everything I do.
- **User:** Open my Downloads folder.
- **Pulse:** Opening Downloads. I'm reading the folder contents. I found 24 items including Documents, Images and Videos. What would you like to do next?

## Built with Open Technologies

Pulse is powered by open technologies including local language models, speech recognition, text-to-speech and wake-word detection.

The project exists to demonstrate that capable AI assistants can be built while respecting user privacy and keeping users in control.

## Running the App

To run the app:
1. First, run the `run.bat` file present in the root folder.
2. Then, navigate to the `ui` folder and double click on `pulse-ui` to start the user interface.
